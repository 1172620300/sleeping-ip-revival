# 网页演示模板（imaideo 适配）

## 编剧资料

故事想法 / 创作篇幅 / 主题 / 情感承诺 / 冲突 / 转折 / 结尾

人物：姓名 / 动机 / 性格或秘密 / 人物弧光 / 语言特点

大纲：场次 / 事件 / 因果关系；正文：场次 / 画面动作 / 对白或旁白

连续性：伏笔埋设与回收 / 人物位置与关系 / 道具状态转移 / 世界规则

## 通用导演资料

依据已确认剧本 v{revision}
画幅：{ratio}
风格：{style}
参考资产：{name} v{version}：{description}
景别：{framing}；运镜：{camera}；时长：{duration}
画面：{description}
动作：{action}
对白（{tone}）：{dialogue}
声音：{sound}
接续状态：{continuity}
衔接方式：{transition}

Seedance 格式预览增加“画幅风格、核心人物、参考资产、时间轴分镜、接续状态、音效、强制禁止项”栏目；H3 格式预览使用 Shot 标记。两者是缩减后的可编辑文字示例，不是可直接提交的模型请求，也没有执行上游模型专属验证器。

所有模板带有“预置示例素材 + 当前编辑字段拼装；不是实时 AI 输出”声明。首次更新和覆盖修改均在界面确认后执行。
