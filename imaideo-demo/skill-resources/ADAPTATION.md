# IP 共创演示适配规则

## 编剧

采用来源 skill 的“策划→人物→结构→单集→连续性检查”方法。策划记录主题、情感承诺、冲突、转折与结尾；人物记录动机、性格、弧光和语言特点；连续性记录伏笔、人物位置、道具转移与世界规则。

不强制爽剧冲突、付费断章或 60–100 集规模。用户明确选择本地演示，因此三个原创世界均使用固定约 60 秒单集；篇幅选项是创作记录，不会触发生成或自动拉伸。任务的交付时长仍是投稿校验依据。

确认将整份编剧资料保存为不可变版本；编辑想法、篇幅、梗概、人物、策划、大纲、剧本或台账均需重新确认。原有镜头文字、提示词与历史版本保留。

## 导演

采用来源 skill 的资产先行、外观锁定、景别/动作/声音/语气、具体接续状态及分级检查方法。资产确认保存所选资产的完整版本副本。引用必须属于项目 IP，且为任务开放资产或本 IP 个人参考。

默认横屏 16:9、换机位衔接、通用文本模板。用户可改成 9:16 或 21:9，选择末态延续/空镜过渡及 Seedance/H3 格式预览。这些均为网站改编示例，不承诺上游模型兼容性或真实接口参数。分镜预演仍用现有横屏静帧素材。

载入固定分镜后必须人工对照已确认剧本，再确认版本对应。提示词由已确认人物信息、已确认资产及当前镜头字段拼装；不分析自然语言，也不调用图像或视频模型。改变上游、资产、配置、镜头或提示词，生成结果标记待更新，并取消旧模拟队列。

## 本地检查

“通过”只表示字段/版本/引用检查通过。检查正文、编剧资料完整性与确认状态、资产范围和版本、分镜版本对应、镜头引用、正数时长及任务总时长、提示词完整性和更新状态。剧情、表演、画面、声音及 IP 改编边界始终为“待人工确认”。检查结果附定位提示与时间，资料变化后标记旧报告过期。

## 兼容

旧项目采用惰性兼容字段，保留剧本、镜头、生成结果；旧投稿不做迁移。只有在操作新助手后才启用完整助手门禁。原有版权方审核与投稿流程保持可用。预置分镜只适用于三个原创 IP，资料展示 IP 不进入该流程。
