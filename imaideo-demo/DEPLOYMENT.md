# 部署说明

## 构建

```powershell
npm ci
npm test
npm run build
```

将 `dist/` 目录作为静态站点根目录发布。项目使用 hash 路由，不要求服务器配置路径重写；建议启用 HTTPS，并为带内容哈希的 `assets/*` 设置长期缓存，为 `index.html` 设置短缓存或不缓存。

## 当前模拟功能

正式接入前需要替换：

- IndexedDB 状态服务 → 账号、权限、数据库与对象存储
- 演示身份切换 → 真实登录及创作者/版权方角色权限
- 预置剧本与一致性提示 → 已验证的编剧服务
- 预置图像和视频结果 → 图像/视频生成队列、用量与失败恢复
- 本地任务发布和审核 → 服务端工作流、通知与审计记录
- 示例激励 → 合同、支付、税务与分账系统
- 演示资产授权字段 → 可追溯的真实授权范围、期限、地区与版本

部署本构建不会迁移或读取现有 `imaideo.xyz` 的生产数据。替换主站应单独安排备份、域名路由、回滚方案和验收。
